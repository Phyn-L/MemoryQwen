# Loss-Term Ablation

This document tracks the loss-term ablations for the MemoryQwen reader. The tables use the paper-style notation below:

\[
\mathcal{L}=\mathcal{L}_{\mathrm{QA}}
+\lambda_E\mathcal{L}_{\mathrm{emb}}
+\lambda_T\mathcal{L}_{\mathrm{token}}
+\lambda_C\mathcal{L}_{\mathrm{causal}}
+\lambda_D\mathcal{L}_{\mathrm{distill}}.
\]

Here, `E` denotes embedding reconstruction, `T` causal reconstruction, `C` memory-prefixed causal reconstruction, and `D` full-context distribution distillation. Unless noted otherwise, the distillation runs use `distill_weight=0.3`, `distill_positions=128`, and `distill_entropy_weight=true`.

The completed runs were trained with `embedding_recon_weight=1.0` and therefore form a conditional leave-one-out study over `T`, `C`, and `D`.

## Current Evidence

| Observation | Evidence | Current interpretation |
|---|---|---|
| Token reconstruction is useful | Removing `T` decreases AR F1 from 0.6513 to 0.6358 | Strongest positive evidence among the tested terms |
| Current distillation is not useful | Removing `D` increases AR F1 from 0.6513 to 0.6809 | The combination `D=0.3` with entropy weighting is harmful or redundant in this setting |
| Causal reconstruction is not useful at the current weight | Removing `C` increases AR F1 from 0.6513 to 0.6786 | No positive marginal contribution has been demonstrated |
| Embedding reconstruction is unresolved | All completed runs use `E=1.0` | `E` must be disabled in a matched run before drawing conclusions |
| A pure QA baseline is missing | Existing `04` uses `E=1.0` | `06` is required before claiming auxiliary-loss gains |

These observations are conditional on the current model, data, seed, training budget, and `distill_entropy_weight=true`. They should be confirmed with repeated seeds before being presented as final claims.

## Distillation Follow-up

The first five runs cannot separate the effect of `distill_weight` from the effect of entropy weighting because all distillation-enabled runs use `distill_entropy_weight=true`. After Phase 2, run the following controlled comparisons with `E=0, T=1, C=1`:

| ID | `distill_weight` | `distill_entropy_weight` | Purpose | Status |
|---|---:|---|---|---|
| D0 | 0.0 | false | No-distillation reference with entropy weighting disabled | **Not run** |
| D1 | 0.3 | false | Isolate the effect of entropy weighting | **Not run** |
| D2 | 0.3 | true | Current entropy-weighted setting | Covered by 05 |
| D3 | 0.1 | false | Low distillation weight | **Not run** |
| D4 | 0.5 | false | Higher distillation weight | **Not run** |

Do not change temperature, top-k truncation, and entropy weighting in the same run. Otherwise the source of an improvement or degradation is not identifiable.

## Reporting Rule

The primary comparison should use autoregressive F1 and ROUGE-L, with teacher-forced F1 and perplexity as secondary diagnostics. For the final paper table, repeat the most important configurations with seeds `42`, `43`, and `44`, and report mean ± standard deviation. The minimum repeated set is:

```text
00 Full
05 Full without embedding
06 True QA only
07 Token only
08 Causal only
09 Distillation only
D1 Distillation without entropy weighting
D2 Distillation with entropy weighting
```

No loss term should be called beneficial or harmful from a single seed unless the effect is large, consistent across teacher-forced and autoregressive evaluation, and supported by a matched control.
