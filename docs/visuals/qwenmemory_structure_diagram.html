01 · 写入一次，按问题读取

memory 随文章变化；readout 随问题变化。问答路径没有原文 KV，答案仍可直接读取 memory KV。

02 · 三项开启的损失，两个可选目标

QA 在主通路中计算。下面两条辅助路径分别约束 token 恢复能力和预测分布；它们允许看到的输入不同。

当前基线：L = L_QA + 1.0 × L_token + 0.3 × L_distill
目标 / 配置字段当前权重直接输入监督信号
QA · qa_weight1.0memory KV、问题、readout、历史答案真实答案 token
Token · token_recon_weight1.0各层 memory hidden、位置查询原文 token；最多采样 128 个目标位置
Distill · distill_weight0.3student：memory KV + 原文历史；teacher：原文历史teacher 概率分布；最多采样 128 个位置，按熵加权
Embedding · embedding_recon_weight0各层 memory hidden、位置查询原文输入 embeddings，MSE + 0.5 × cosine loss
Causal · causal_recon_weight0memory KV + 真实原文历史原文 token 的 CE；与蒸馏共用 student 前向
组合方式：memory_objectives() 计算四种辅助损失，objective_total() 与 QA 按独立权重相加；不是旧版的重构二选一。各项归约后再乘权重，数值大小不能直接解释为贡献大小。

03 · 用同一句话看清两种监督

示例原文：Alice moved to Paris in 2019. 为便于理解，以词表示 token；实际按 Qwen tokenizer 的位置处理。

Token 重构：直接核对“记了什么”

输入：整篇文章的 memory + “Paris 所在位置”的查询。

目标：Paris，直接来自原文标签。decoder 不看 Alice moved to，也不看其他原文 token。

若 memory 把城市记错，真实 token 的交叉熵会给出纠正信号。槽 hidden 由完整原文编码得到，原文内容必须经过 memory 才能到达这个 decoder。

蒸馏：对齐“预测分布”

Teacher 输入：Alice moved to。Student 输入：memory + Alice moved to。两者都预测下一个 token。

Teacher 看不到后面的 Paris，因此可能给很多城市分配概率。蒸馏只要求 student 接近这个分布，不直接把 Paris 当作唯一正确标签。

例如（假设数值）：teacher 在 Paris / London / 其余词上的概率为 0.2 / 0.3 / 0.5，而 student 为 0.8 / 0.1 / 0.1，KL 仍会惩罚这个差异，即使原文答案确实是 Paris。

解释边界：当前蒸馏更准确地说是“带 memory 的因果预测向普通因果预测对齐”。它不保证鼓励事实记忆；也不能仅凭 KL 下降推断 memory 在补足语言先验。是否帮助 QA，要由匹配设置的消融验证。熵加权只改变不同位置的相对权重，不会让 teacher 获得未知的正确答案。

04 · 哪些参数收到梯度？

问答与重构共用 writer

QA 梯度经过 readout 和 memory KV 回到 writer；同篇文章的多条 QA 梯度经可微 index_select 累加。Token 重构更新各层 decoder、tied head 的小投影，并回传到 memory slots 与 LoRA。

蒸馏只沿 student 路径回传到共享 LoRA 和 memory writer。Teacher 概率在 torch.no_grad() 内计算；共享 LoRA 更新后，下一步的 teacher 分布仍可能变化。

冻结与训练的边界

冻结：Qwen 原始参数和原始 embedding / 词表权重。训练：memory slots、共享 LoRA、QuestionResampler、开启的 MemoryDecoder 及 token head 小投影。

基线主干计算使用 bfloat16，可训练参数保持 float32。DDP 同步可训练参数的梯度；memory KV 保留在本 rank，指标另做标量归约。

05 · 四种 readout 模式

模式插入 Qwen 前的 readout 来源本基线
memory_questionResampler 读取 question embeddings + 最后层 memory启用，R = 8
memory_onlyResampler 只读取最后层 memory消融选项
learned_prefix所有样本共享的可学习 embeddings，不读取文章或问题消融选项
off不创建 readout 模块，有效 R = 0消融选项

四种模式保留原 memory KV 通道。memory_only / learned_prefix 限制的是插入前的来源；进入 Qwen 后，这些位置仍可读取问题与 memory。readout_length = 0 也会关闭 readout。
