QwenMemory：组件、数据流与损失函数

当前代码实现的论文风格方法说明。主路径为 Qwen3 冻结主干 + LoRA + 可复用 memory KV；默认训练使用 QA loss 和 memory-only context LM。AE-LM、KL 蒸馏与 question resampler 均为可选分支。

1. 核心结论

QwenMemory 用少量、与问题无关的 memory slots 压缩 context，并把 slots 在 Qwen 每层形成的 Key/Value cache 复用于同一 context 的全部问题。

它没有单独的 memory encoder。Qwen 自己编码 [context | memory]：context 位置读其因果历史，memory 位置从 context 汇聚信息。随后丢弃 context KV，只保留 memory KV；问题期只能借由这个 prefix 访问原 context。

Writercontext 与 M 个可学习 slots 一次前向；Qwen 主干冻结，仅 LoRA 更新；输出 layer-wise memory states 与 cache。
ReaderQA 行按 qa_context_indices 取所属 cache，Qwen 在 [question | answer] 上继续前向/生成。
SupervisionQA CE 学下游问答；memory-only context LM 强迫 memory 装下 context 内容；AE/KL 是可选的压缩训练目标。

3. 组件逐一解释

3.1 Frozen Qwen + trainable LoRA

原始 Qwen3 causal LM 参数冻结。rank-8 LoRA（α=16）附着于 q/k/v/o attention 投影及 gate/up/down MLP 投影。每个改造线性层计算 W₀x + (α/r)B(Ax)：保留预训练语言知识，同时让模型适应 memory slots 的输入布局。

3.2 Memory slots

memory_tokens ∈ R^(M×H) 是全局可学习参数，默认 M=8。它们不是“每篇文档存一份参数”；真正的文档表示是这些 slots 经过 Qwen context pass 后的 hidden states/KV。可选 token_embed、vocab_mean 初始化，以及 slot 的因果互注意力。

3.3 Per-layer MemoryDecoder

每个 Qwen layer 配置一个 decoder。它将该层 [M,H] memory 投影至 D=256，以可学习的 context-position query 对 memory cross-attend，经 LayerNorm/FFN 得到 bottleneck hidden。context-LM 模式直接分类 token；MSE/cosine 模式则额外投回 H 以重构 embedding。

3.4 Vocabulary heads

默认 context-LM 由所有 layer decoder 共用一个 [V,D] vocabulary head，避免 N 份巨大词表头。可选 head_mode=tied 使用 W=E·A（冻结 embedding E + 小型 adapter A）。AE-LM 则直接用 Qwen 自己的 tied unembedding，零新增 head 参数。

3.5 Optional QuestionResampler

当 readout_length=R>0 时，R 个 latents 在 D=256 宽度上 cross-attend [question; memory]，产生 R 个 H 维 token embedding，插入 question/answer 间。它只在提问期计算，memory cache 仍保持可复用。

4. 数据流与张量形状

4.1 一次 context 编码

context_ids       [C, L]
X = Emb(context)  [C, L, H]
S = memory_tokens [M, H] → [C, M, H]
sequence = [X; S] [C, L+M, H]
Qwen block-causal forward
layer_memory Z    [C, N, M, H]
memory_cache      per-layer KV restricted to M slots

这次 forward 不计算 vocabulary logits。context rows 是普通因果行；memory rows 读取全部有效 context，默认不读别的 slot。再从 full cache 中按位置截取 M 个 slots 的 K/V，context K/V 不会进入问题期。

4.2 多个 QA 共享一个 prefix

question_embeds   [Q,Lq,H]     answer_embeds [Q,La,H]
indices           [Q]          = qa_context_indices
selected_cache    = gather(memory_cache, indices)
optional readout  [Q,R,H]
Qwen continuation past=selected_cache, inputs=[question; readout?; answer]
logits            [Q,Lq+R+La,V]  (only answer labels active)

训练按 context 采样最多 qa_per_context 个 QA；同一 context 的多个问题在 Q 维上展开，但编码只跑一次。生成时亦先编码一次，再按 context 分组 prefill/greedy decode。

5. 注意力可见性：防止信息旁路

Query可以看什么为何这样设计
context[t]有效 context[≤t]标准 causal LM，不能偷看未来。
memory[m]全部有效 context；可选 slot ≤m将 context 汇聚入 M 个瓶颈。
question[t]全部 memory + question 因果前缀问题只能经 memory 获得 context 信息。
readout[r]全部 memory + 全部有效 question问题条件化读取，不能查看 answer。
answer[t]memory + question/readout + answer 因果前缀支持 teacher forcing 与自回归生成。
数值稳定性：padding query 维持 self-edge，屏蔽值使用 finfo(dtype).min，避免 all--inf softmax 产生 NaN。数据加载器会过滤 tokenization 后为空的 context。

6. 损失函数

6.1 总损失

L = λqaLqa + λrecLrec + λaeLae + λkdLkd

实现中 combine_losses() 组合各项。默认 λqa=λrec=1，AE 与 KL 权重为零。

DEFAULT ON① QA answer cross-entropy

qa_loss() 进行标准 next-token shift，但 question/readout label 全为 -100，只监督 answer。每条 QA 先按有效 answer token 数归一化，再平均，避免长答案获取更大样本权重。

Lqa = meanq[|Aq|−1 Σt∈Aq CE(yq,t,pθ(·|memory,q,y<t))]

DEFAULT ON② Memory-only context LM

当前 reconstruction_loss=context_lm。对于 context token t，decoder 的 query 使用 t−1 的位置编码，但 decoder 只能 attention 到 memory，完全看不到任何 context token。每 context 每步至多随机抽取 P=256 个 token target，N 层 decoder loss 再平均。

Lctx = (1/N)Σℓ mean(b,t)∈P CE(xb,t, head(dℓ(Zb,ℓ,t−1)))

ALTERNATIVEEmbedding reconstruction

设 reconstruction_loss 为 mse、cosine 或 mse_cosine 时，decoder 输出 H 维 embedding，与原 context embedding 比较。这与 context LM 二选一，不会同时运行。

Lmse=mean‖ẑ−z‖²； Lcos=mean(1−cos(ẑ,z))； Lrec=Lmse+λcosLcos

OPTIONAL / OFF③ Memory-prefix AE-LM

ae_lm_weight>0 时，memory KV 作为 prefix，冻结 Qwen 以 teacher forcing 预测 P(x_t | memory,x_<t)，并以自身 tied unembedding 打分。这让预训练 LM 承担语言解码，memory 更集中承载语言先验无法预测的残差信息。

OPTIONAL / OFF④ Full-context KL distillation

distill_weight>0 时必须打开 AE-LM。teacher 是 encoder pass 的 plain causal context hidden（不额外跑 backbone）；student 是 memory-prefix AE hidden；teacher 不反传：

Lkd=T²·KL(pteacher(·|x<t) ‖ pstudent(·|memory,x<t))

distill_positions、topk、entropy weighting 用于控制词表级分布的代价。

7. 训练、验证与推理

阶段路径应关注什么
训练encode prefix → QA continuation → QA/context-LM；按开关追加 AE/KL → backward/clip/AdamW主干 bf16；slots/LoRA/decoders/head/resampler 默认 fp32；词表 logits 分块+checkpoint。
Teacher-forced 验证同一 prefix/cache，输入 gold answerQA loss、PPL、reconstruction loss；不等于真实生成质量。
Autoregressive 验证共享 prefix，逐 token greedy decodeEM/F1/ROUGE-L/first-token EM 是下游主要证据。
Memory ablation保持网络与问题不变，置零或随机化 memory鉴别模型是否真从 slots 获取 context，而不是仅依赖语言先验。
重要区分：memory-only context LM 是诚实的“是否装入内容”探针；teacher-forced AE 会受到强语言先验影响；论文主结论应该基于 context-disjoint 的 autoregressive QA 指标。

9. 风险与实验建议

  1. 容量与读取是不同假说：增大 M、允许 slot attention、增加 readout R 分别改变写入容量、slot 协调和问题条件化读取，应分开消融。
  2. 避免 QA 级泄漏：train/validation 应按 context 切分，而不是按 QA 行切分；同一 context 的不同问题不能跨 split。
  3. 记录损失尺度：context-LM 初始接近 ln(V)，embedding-MSE 在不同量纲；切换 objective 必须重新审视权重。
  4. 完整证据链：建议报告 full、zero-memory、random-memory、不同 M、不同 R，并以 context-disjoint autoregressive EM/F1 给出结论。
