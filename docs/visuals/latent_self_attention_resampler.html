先独立提取，再在中途通信，最后用协调后的 latents 继续查询 context。只有一次显式 slot 间交互，容量和计算更低。

只改变初始查询槽位的分工；第一层读取出的新信息不会在第二次读取前通过 self-attention 传播。

改变的是什么

没有 self-attention 时，每个 latent 都能看完整 context，但它们只能通过各自的 cross-attention 结果间接形成分工。

加入 self-attention 后，一个 slot 发现的实体、时间或关系可以传给另一个 slot，影响后续查询。它增加的是 compressed slots 的通信，不是 context 的可见范围。

每个 block 内：通信最充分；中间一次：成本和表达力折中；开头一次：只测试初始查询协调。

固定 memory 长度、宽度、数据、损失和随机种子；同时报告 QA、reconstruction、参数量、吞吐和显存。新增 attention 的参数会增加总容量，最好再提供参数匹配的 FFN 缩小对照。
